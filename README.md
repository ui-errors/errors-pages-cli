# UI Errors

Beautiful error pages installer.

## Install

```bash
npm install -g ui-errors
```

or

```bash
npx ui-errors
```

---

# Features

- 404 pages
- 500 pages
- Random installs
- React support
- Next.js support
- Vue support
- Svelte support
- Express support
- Vite support
- Static HTML support
- Interactive TUI

---

# Usage

```bash
ui-errors
```

---

# Controls

- ↑ ↓ navigate
- Enter select
